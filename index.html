PERSONAL SOFTWARE · LOCAL MONITORING

A clearer view of backup power.

EcoFlow Monitor is a personal application that reads a compatible EcoFlow power station over Bluetooth and presents battery status in a dashboard hosted on the owner's Raspberry Pi.

01

Monitor locally

View charge, input and output power, battery history, configured battery limits and an estimated backup runtime.

02

Record power changes

Log inferred battery operation, detected AC input, low battery and connection events. Monitoring continues without internet access.

03

Connect notifications

Optional Pushover and Gmail helpers support explicit notification tests. Automatic delivery from trigger rules is being configured and is not currently enabled.

Why Google access is requested

The optional Gmail integration requests permission to send notification emails from the account the owner authorizes. Basic Google account identity is used to verify that the intended sender account was selected. It does not request permission to read the inbox, delete messages, or manage contacts.

Authorization is completed directly with Google. Credentials are stored on the owner's Pi and are not embedded in this public website.

About this website

This is a public information site, not the live dashboard. It has no Google sign-in, access to the power station, live telemetry or notification credentials. The application is intended for personal use, not as a public service.
