DATA HANDLING

Privacy policy

Effective October 26, 2026

This policy describes EcoFlow Monitor, a personal battery-monitoring application maintained by the GitHub account pastorialeader, and this public information website.

Application data

The locally hosted application receives battery and power readings over Bluetooth through a local bridge. It stores configured rule thresholds, recent battery history and event records on the owner's Raspberry Pi. The public website does not receive or display these readings.

Google account access and purpose

The optional Gmail integration requests Gmail send permission and basic OpenID/email identity information. Account identity is used to check that the owner authorized the intended sender. Gmail access is used to send explicitly requested test emails and, if subsequently enabled, configured power and battery notification emails. Automatic trigger-based email delivery is not currently enabled.

The integration does not request permission to read inbox messages, search the mailbox, delete mail, or manage contacts. It creates outgoing messages locally, including the intended recipient, subject and message body, and submits them to Google's Gmail API.

Storage and protection

OAuth credentials, including a refresh token, the sender address and client configuration are stored in private files on the owner's Pi, outside the source repository. On the Pi, the configuration directory is restricted to its owner and credential files are readable and writable only by that owner; administrators can still access them. These files are not encrypted by the application. Google API connections use HTTPS.

Pushover credentials, when configured, are also stored privately on the Pi. Credentials are not published in this website, source code or GitHub repositories. No credential should be included in a support request.

Sharing and service providers

When an email is sent, its recipient, headers and body are transmitted to Google for delivery and become available to the recipient and their mail provider. Gmail may retain sent messages according to the account's settings and Google's policies. Pushover receives notification content and routing credentials when a Pushover notification is explicitly sent or later configured for automatic delivery.

The project does not sell Google user data, use it for advertising, or use it to train AI or machine-learning models. Google user data is used only for the notification and account-verification functions described here. EcoFlow Monitor's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Retention and deletion

Credentials remain on the Pi until replaced or removed by its owner. The dashboard currently retains seven days of sampled history and up to 3,000 event records; configured thresholds remain until changed or removed. The Gmail helper does not create a local archive of sent message contents. Removing local files does not delete messages retained by Google or recipients.

The owner can disconnect Gmail access using Google Account third-party connections, stop using the email helper, and delete its local authorization files. Revoking access prevents further use of that grant; deleting a token file alone does not revoke Google's grant. Dashboard history and settings can be removed from local storage by the owner.

Public website

This site contains static information pages. It does not use application analytics, advertising scripts, sign-in forms or application tracking cookies. GitHub Pages hosts the site and may process connection information, such as IP addresses and request logs, under GitHub's privacy statement. Linked services have their own privacy practices.

Changes and contact

This policy will be updated when the application's data practices change. The effective date appears above. Questions or deletion assistance can be requested through the public information site's issue tracker. Do not post email addresses, tokens, device identifiers or other private information in a public issue.
